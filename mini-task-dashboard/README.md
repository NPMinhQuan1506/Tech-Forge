# Mini Task Dashboard

Project hoc React + TypeScript + SCSS theo cach:

1. hoc mot concept nho
2. ap ngay vao app
3. sua sai va doc lai source

## Stack

- React
- Vite
- TypeScript
- SCSS

## Day 1 da co

- `TaskStatus` union type
- `Task` interface
- `Task[]` render bang React
- Layout `Header / Sidebar / Task List / Task Card`
- SCSS variables
- SCSS nesting
- Flex layout

## Cau truc

- `src/types/`: type va interface dung chung
- `src/data/`: du lieu mau va lesson notes
- `src/components/`: layout, panel, task UI
- `src/styles/`: abstracts, base, layout, components
- `docs/`: note hoc tung ngay

## Chay project

```bash
npm install
npm run dev
```
